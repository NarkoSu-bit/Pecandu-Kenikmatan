# ai-happy-01

A program that draws one joyful moment: a golden retriever puppy
mid-leap, catching a red ball in golden-hour light while autumn leaves
swirl around it — a fresh, specific reason to smile, not a stock smiley.

## Run it

```sh
python3 main.py
```

Writes the picture to `/output/entry.png` (1024x1024 PNG, deterministic —
same bytes every run).
