# news-image-01

A program that draws a one-page newspaper front page summing up the
world news of Friday 13 November 2026: Ukraine peace talks widening to
Europe, the Gulf, Nvidia's chief resigning, the Microsoft 365 outage,
China's Pacific drills, the IEA oil outlook, and more.

## Run it

```sh
python3 main.py
```

Writes the front page to `/output/entry.png` (1024x1024 PNG).
